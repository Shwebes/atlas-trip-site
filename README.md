# Atlas — учебный сайт о путешествиях

Минималистичный адаптивный сайт-путеводитель с пятью страницами, двенадцатью направлениями, фильтрами маршрутов по интересам и интерактивным 3D-глобусом.

## Состав проекта
- `index.html` — главная страница и 3D-глобус.
- `destinations.html` — двенадцать стран с описаниями.
- `routes.html` — примерные маршруты с фильтрами по хайкингу, гастрономии, истории, природе и культуре.
- `journal.html` — редакционные заметки.
- `about.html` — информация о проекте.
- `styles.css` — общий адаптивный дизайн.
- `app.js` — мобильное меню, демонстрационная форма, выбор стран, фильтры маршрутов и заготовка событий кликов.
- `globe.js` — сцена Three.js, вращение глобуса и кликабельные маркеры двенадцати направлений.
- `assets/` — локальные фотографии новых направлений.
- `photo-credits.html` — авторы и лицензии фотографий новых направлений.

## Как запустить на Windows

### Вариант 1 — Python
1. Установи Python 3.11 или новее с официального сайта https://www.python.org/downloads/ (при установке отметь `Add Python to PATH`).
2. Распакуй архив `atlas-trip-site.zip` в удобную папку.
3. Открой папку проекта в Проводнике.
4. В адресной строке Проводника введи `cmd` и нажми Enter.
5. Выполни команду:
   ```bat
   py -m http.server 8000
   ```
6. Открой браузер по адресу http://localhost:8000 .
7. Чтобы остановить сервер, вернись в окно командной строки и нажми `Ctrl+C`.

### Вариант 2 — Visual Studio Code
1. Установи Visual Studio Code и расширение Live Server.
2. Открой распакованную папку проекта.
3. Нажми правой кнопкой на `index.html` и выбери `Open with Live Server`.

Не открывай `index.html` двойным щелчком: ES-модули Three.js обычно требуют запуск через локальный HTTP-сервер.

## Как опубликовать сайт на GitHub Pages

В репозитории уже есть workflow для публикации сайта из ветки `main` или `master`.

1. Создай публичный репозиторий на [GitHub](https://github.com/new). Если GitHub предлагает создать README, `.gitignore` или лицензию, оставь эти пункты выключенными — файлы проекта уже есть.
2. Установи [GitHub Desktop](https://desktop.github.com/) и добавь папку проекта как локальный репозиторий (**File → Add Local Repository**). Если GitHub Desktop сообщает, что папка ещё не является репозиторием, выбери **create a repository** и укажи эту папку.
3. Создай первый commit, затем нажми **Publish repository**. Для общедоступной ссылки сними отметку **Keep this code private**.
4. До первого запуска открой репозиторий на GitHub → **Settings → Pages**. В разделе **Build and deployment** выбери источник **GitHub Actions** и нажми **Save**. Пока Pages не включён этим способом, workflow может завершиться ошибкой `Get Pages site failed: Not Found`.
5. Открой вкладку **Actions** и дождись успешного завершения workflow **Deploy static site to GitHub Pages**. Если репозиторий организации ограничивает права workflow, проверь **Settings → Actions → General → Workflow permissions**.
6. Ссылка появится в **Settings → Pages** и в описании завершённого workflow. Обычно адрес имеет вид `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

После изменений опубликуй новый commit через GitHub Desktop — сайт обновится автоматически. GitHub Pages может собирать базовую статистику посещений репозитория, но не полноценную аналитику просмотров страниц. Для посещаемости отдельных страниц подключи счётчик веб-аналитики по инструкции выше. Не добавляй в публичный репозиторий секретные ключи или приватные данные.

## Что нужно для работы глобуса
Глобус использует Three.js и текстуру Земли с внешних CDN. Для 3D-модели нужен интернет и браузер с поддержкой WebGL. Если текстура недоступна, остаётся базовая цветная сфера; остальная часть сайта продолжит работать.

## Подключение счётчиков для лабораторных
Счётчик LiveInternet с ID `Atlas` установлен на всех HTML-страницах сайта. Он передаёт сервису URL страницы, заголовок страницы, источник перехода и характеристики экрана. Для опубликованного сайта размести соответствующее уведомление об аналитике и обработке этих данных.
- LiveInternet: счётчик уже подключён; после публикации проверь в кабинете сервиса, что домен и просмотры отображаются корректно.
- Top100 / Rambler с ID проекта `7753152` установлен на всех HTML-страницах; его видимый логотип отрисовывается в подвале через `drawLogoTo`. Проверяй сбор статистики в кабинете Top100 после публикации сайта.
- Top.Mail.Ru с ID счётчика `3806743` установлен на всех HTML-страницах и отправляет просмотры страниц. Проверяй сбор статистики в кабинете Top.Mail.Ru после публикации сайта.
- Sber Ads: вставь код счётчика в рекомендованное сервисом место на всех страницах; настройки событий делай в интерфейсе сервиса.
- MyTracker: используй актуальный код, выданный в кабинете MyTracker, и инструкцию для веб-проекта.

Для учебных целей в `app.js` есть заготовка `window.dataLayer` с событием `atlas_link_click`. Это не отправляет данные в аналитические системы само по себе. Чтобы событие стало видимым в сервисе, настрой передачу по его актуальной документации.
Также Top100 получает события `view_route` при открытии `routes.html` и `view_destination` при открытии `destinations.html`. Остальные страницы эти цели не отправляют.

## Важные ограничения
- Подписка на главной странице демонстрационная: данные никуда не отправляются.
- Сайт не бронирует поездки и не является туристическим агентством.
- Описания сезонов и маршрутов — ознакомительные; перед реальной поездкой проверяй актуальные условия.
- Для отчётов лабораторных нужны реальные данные счётчиков за период наблюдения. Не подменяй их вымышленными значениями.
